# Yana Libina — Portfolio

Personal site for [yanalibina.com](https://yanalibina.com).

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Motion

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content

Edit copy, work bars, email, and trail images in `src/content/site.ts`.
Images live in `public/images/`.
